## 📖 About

A compact API that brings together **Node.js, TypeScript, Express,
Redis, MongoDB and Docker** — a small “all-in-one” stack exercise.

## ✨ Features

- Express + TypeScript
- Redis client (`redisClient.ts`)
- MongoDB data layer
- Docker-ready
